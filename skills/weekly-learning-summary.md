# 每周学习总结

把 `D:\xuexi\学习笔记.md` 里某一周的条目整理成结构化周总结，存到 `D:\xuexi\周总结\`。

## 0. 配置

| 项目 | 默认值 |
|---|---|
| 笔记文件 | `D:\xuexi\学习笔记.md` |
| 笔记日期标记 | 行首的 `## YYYY-MM-DD`（允许 `#`~`######`、允许 `2026/1/7`） |
| 输出目录 | `D:\xuexi\周总结\` |
| 输出文件名 | `<ISO年>-W<两位周号>.md`，如 `2026-W02.md` |

笔记文件不在默认位置时，先用 `glob` 在 `D:\xuexi` 下找 `*笔记*.md`、`*notes*.md`，找到后确认一次再继续；找不到就停下来问用户路径，不要新建空文件假装读过。

## 1. 确定周范围

- 用户给了日期：取该日期所在自然周（**周一 00:00 ~ 周日 23:59**）。
- 只说"这周/本周"：取今天所在自然周。
- 说"上周"：今天往前推 7 天所在自然周。
- 用系统当前日期作为"今天"，不要猜。

算出并记住：`Start`（周一）、`End`（周日）、ISO 年与周号。

## 2. 提取该周笔记

按日期标记逐行归属，再按范围过滤。**不要用"搜索日期字符串"的方式**——日期可能出现在无关的行里。

```powershell
$notes  = 'D:\xuexi\学习笔记.md'
$start  = '2026-01-05'   # 本周一
$end    = '2026-01-11'   # 本周日

$cur = $null
$out = foreach ($line in Get-Content -LiteralPath $notes -Encoding UTF8) {
  if ($line -match '^\s{0,3}#{1,6}\s+(\d{4})[-/.](\d{1,2})[-/.](\d{1,2})') {
    $cur = '{0:d4}-{1:d2}-{2:d2}' -f [int]$Matches[1], [int]$Matches[2], [int]$Matches[3]
    continue
  }
  if ($cur -and $cur -ge $start -and $cur -le $end) { "$cur`t$line" }
}
$out -join "`n"
```

把结果按日期分组，作为第 3 步的唯一素材来源。**只依据这里实际出现的文字，不补写、不推测。**

## 3. 生成周总结

固定用这个骨架，输出为 Markdown：

```markdown
# 学习周总结（2026-01-05 ~ 2026-01-11）

## 一、本周概览
- 记录天数：N 天（实际出现日期标记的天数）
- 条目数：N 条
- 一句话概括：<基于本周条目总结，不超过 50 字>

## 二、完成事项
- <按天或按主题列出，每条注明日期>

## 三、掌握的知识点
- **<概念>**：<用自己的话一句说明>
  （条目里出现"弄懂/理解/搞清楚了/原来是"等表述时归入本节）

## 四、遇到的问题
- <条目里出现"卡住/不懂/报错/待查/为什么"等表述时归入本节>
- 若本周没有这类记录，写"本周未记录待解决的问题"，不要编造

## 五、下周计划
- <来自条目里明确写下的待办；没有就写"待补充">

## 六、与上周的变化
- <上周文件存在时读 `D:\xuexi\周总结\<上周>.md`，对比条目数与主题，写 1~3 条；文件不存在则整节省略>
```

写作用词要求：中文、简洁、不堆形容词；不把笔记原文整段搬过来，要压缩成要点；概念解释里的小代码片段可以保留。

## 4. 落盘

1. 输出目录不存在就创建。
2. 写入 `D:\xuexi\周总结\<ISO年>-W<周号>.md`（UTF-8，无 BOM）。
3. 若同名文件已存在：**先读它**，再决定是覆盖还是合并，并在回复里说明你覆盖了什么。
4. 最后把完整正文贴回对话，并给出文件链接。

## 5. 边界情况

| 情况 | 处理 |
|---|---|
| 本周在该范围内没有任何条目 | 明确说"本周无记录"，列出笔记中最近有记录的日期，然后停手，不生成空周报 |
| 笔记里完全没有日期标记 | 说明需要 `## YYYY-MM-DD` 格式（见下方示例），问用户是否要我先帮忙整理成带标记的格式 |
| 用户给的范围跨多周 | 按自然周拆成多份，分别落盘 |
| 笔记文件不存在 | 询问正确路径，不要创建 |

## 6. 笔记格式示例

```markdown
## 2026-01-05
- 看了 Agent 的 ReAct 循环，理解了"思考-行动-观察"三步
- 卡在工具调用的参数校验，报错 invalid schema

## 2026-01-07
- 弄懂了 frontmatter 里的 name 必须是 kebab-case
- 待办：把 Q02 的代码跑通
```

日期标记必须是独立的一行标题。除此之外不限制笔记写法，追加式记录即可。
